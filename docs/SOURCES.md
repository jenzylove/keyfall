## Wording to use on the landing page

- Say "one of the first" for NEAR, never "the first". Algorand had a Falcon signed mainnet transaction in November 2025 and QRL has run a hash based signature chain since 2018.
- Say "about a quarter to a third of all bitcoin" has an exposed public key (Citi 25%, Glassnode about 30% combined, BIP-361 over 34%). Say "nearly 10%" only if you mean the structural share.
- Say BIP-361 is a "draft proposal". Do not say it will freeze coins.
- Harvest now, decrypt later is mostly about encrypted data. For chains the more exact phrase is "exposed public keys can be attacked once a quantum computer exists". Citi says old transactions cannot be reversed.

## Not verified

- Claim 3, few ML-DSA-65 transactions on NEAR mainnet. No public count, dashboard or article found, and nothing dated October 2026. The only documented rotation is one Fireblocks test account (https://www.fireblocks.com/blog/post-quantum-key-rotation-ml-dsa-near, 2026-10-01, six mainnet transactions in total). Do not state a number. A safe line is "opt in, so uptake starts small", or pull a count yourself from NEAR RPC or an indexer.
- NEAR's own blog post. I found only the PR Newswire release reposted on Webull, not a near.org page or docs page confirming activation. The FastNear docs examples all use testnet. One MEXC item dated July 10 conflicts with the July 20 date, so keep the date as "July 2026".
- The nearcore 2.13.0-rc.1 page shows "23 Jun" with no year, and the exact date protocol version 85 activated on mainnet was not confirmed from a primary source.
- The Glassnode 30.2% / 6.04M BTC figure. Seen only in search summaries. The Cointelegraph article gives 9.6% structural plus 20.6% operational.
- NIST IR 8547 Final text. The CSRC page confirms Final status on 2026-10-27 but I could not read its contents. Only the November 2024 draft table is quoted directly.
- Project Eleven's and Deloitte's and River's own pages. Not reached. Project Eleven figures appear only through secondary articles. Chaincode's "20% to 50%" appears only in ForkLog's summary, and the report PDF could not be read by the fetch tool.
- QRL 2.0 mainnet status. Taken from QRL pages in a search summary, not fully fetched.
